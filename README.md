# AdminEye

PowerShell-based Windows system health and diagnostics toolkit
for Systems Administrators.

## Current Status

🚧 Early Development

### Current Checks

- [x] Basic system identification
- [ ] CPU utilization
- [ ] Memory utilization
- [ ] Disk space
- [ ] System uptime
- [ ] Service health
- [ ] Windows Update
- [ ] Network health
- [ ] Defender status
- [ ] BitLocker status
- [ ] HTML reporting

## Goals

AdminEye aims to provide Systems Administrators with a quick,
consistent way to assess the health of Windows systems.

## Requirements

- Windows PowerShell 5.1+
- Windows 10/11 or Windows Server
